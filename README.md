# 🏛️ MUDRA Atelier — Haute Sartorial Menswear Platform

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://dashboard.render.com/blueprints/new?repo=https://github.com/shashankshashank4023-cmyk/mudra-clothing)
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/shashankshashank4023-cmyk/mudra-clothing)

A full-stack, bespoke luxury menswear e-commerce and sartorial concierge web application engineered with **React 18**, **Vite**, **Express 5**, and a zero-dependency portable database engine.

---

## 🌟 Key Architectural Features

- **Haute Menswear Collections**: Curated 100% verified luxury menswear (Raw Silk Bandhgalas, Sherwanis, Italian Cashmere Overcoats, Double-Breasted Blazers).
- **Interactive Bespoke Studio**: Real-time custom monogram initial customizer with imperial thread selection and Cupro lining choices.
- **Sartorial Style Matchmaker Quiz**: Dynamic recommendation engine tailoring outfits based on body proportions, events, and color tones.
- **Advanced Cash on Delivery (COD) Engine**:
  - Real-time PIN code serviceability validation (Metro White-Glove Concierge vs Express Insured Courier).
  - Luxury insurance ceiling enforcement (₹50,000 maximum COD cap).
  - Cryptographic delivery verification tokens (`COD-ATELIER-XXXX`).
  - Pre-payment trial & inspection authorization.
- **Atelier Executive Suite (Admin Portal)**:
  - Password-protected boutique manager dashboard (Default Passkey: `2026`).
  - Real-time Gross Revenue, Order Volume, and Silhouette KPIs.
  - One-click COD Cash Collection settlement with automated receipt vouchers (`RCP-CASH-XXXXX`).

## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/shashankshashank4023-cmyk/mudra-clothing.git
cd mudra-clothing

# 2. Install dependencies
npm install

# 3. Build frontend production bundle
npm run build

# 4. Start full-stack server (Port 3000)
npm start
```
